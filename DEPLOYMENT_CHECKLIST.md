## 🔧 Troubleshooting Deployment

### Issue: Blank Page on Load
**Solution**: 
- Check browser console for errors
- Verify all JavaScript files are loading
- Check network tab for 404s
- Ensure chatbot.js path is correct

### Issue: Auth Gate Not Redirecting
**Solution**:
- Clear localStorage in browser
- Check if isLoggedIn flag is being set correctly
- Verify auth-gate.html exists and is accessible
- Check for JavaScript errors in console

### Issue: Dark Mode Not Working
**Solution**:
- Verify data-theme attribute is being set
- Check CSS variables are defined in :root
- Clear browser cache
- Test in incognito/private window

### Issue: Mobile Layout Broken
**Solution**:
- Verify viewport meta tag present
- Check media queries are correct
- Test at 768px breakpoint width
- Check for elements with min-width > 100%

### Issue: Calculator Not Saving
**Solution**:
- Check localStorage is not full (max ~5-10MB)
- Verify currentUser object is set in localStorage
- Check browser settings allow localStorage
- Implement backend API when ready
