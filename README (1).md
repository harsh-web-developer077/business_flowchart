## 🚢 Deployment Instructions

### Option 1: Deploy to Render (Recommended)

1. **Push to GitHub**
   ```bash
   git add .

   ```

2. **Connect to Render**
   - Go to https://render.com
   - Click "New +"

   - Connect your GitHub repository

## 💡 Calculator Details

### Investment Components

1. **Land Cost** = Land Area × Land Price per sq ft
2. **Business Setup** = Pre-configured amount per business type
3. **Initial Stock** = Pre-configured inventory cost
4. **Equipment** = Fixtures, furniture, and equipment costs
5. **Monthly Salary** = Salary per employee × Number of employees
6. **Operating Costs** = First month utilities, rent, maintenance
7. **Total Investment** = Sum of all above components

### Example Calculation

**Building Materials Shop (Highway Area, 10,000 sq ft, 2 employees)**
- Land Cost: 10,000 × 6,000 = ₹60 Lakhs
- Business Setup: ₹20 Lakhs
- Initial Stock: ₹80 Lakhs
- Equipment: ₹4.5 Lakhs
- Monthly Salary: 70,000 × 2 = ₹1.4 Lakhs
- Operating Costs: ₹1.5 Lakhs
- **Total: ₹1.67 Crore**
